## Objetivo

Visión debe expresar hacia dónde apunta Entrenemos como producto y como empresa.

Queremos posicionar a Entrenemos como el sistema operativo que responde a la relación cotidiana entre un entrenador y un atleta y que puede acompañar toda la trayectoria de ese vínculo.

La sección debe transmitir una idea de legado:

- Cada entrenador construye una forma de trabajar y acompañar.
- Cada atleta construye una trayectoria.
- Cada rutina, entrenamiento, registro y conversación forma parte de esa historia.
- Entrenemos organiza, conecta y conserva ese contexto.
- Lo registrado hoy puede ayudar a comprender y continuar el proceso mañana.
- La tecnología ofrece estructura y continuidad.
- El criterio, el compromiso y las decisiones siguen siendo humanos.

No queremos hablar de legado como fama, reconocimiento público o resultados extraordinarios. El legado debe entenderse como el recorrido que entrenador y atleta construyen con el tiempo.

## Posicionamiento

Entrenemos no es solamente una aplicación para cargar ejercicios.

Es un sistema operativo para el trabajo compartido entre entrenadores y atletas:

- El entrenador planifica, acompaña, se comunica, observa y toma decisiones.
- El atleta entrena, registra, expresa cómo se siente y participa activamente del proceso.
- Entrenemos reúne ese trabajo y le da continuidad.

La mensajería dentro del producto es una función real y confirmada. Sin embargo, comunicación no significa únicamente enviar mensajes: también implica compartir planificación, registros, sensaciones, dificultades, seguimiento y contexto.

No presentes a Entrenemos como reemplazo del entrenador ni como responsable automático del progreso.

## Jerarquía tipográfica

El título es el protagonista.

**EL PROGRESO DEJA UNA HISTORIA.**

**CONSTRUIMOS EL SISTEMA  
QUE LE DA CONTINUIDAD.**

Podés utilizar mayúsculas si funcionan correctamente con la tipografía actual, pero evitá que el texto parezca agresivo.

Tratamiento sugerido:

- “El progreso deja una historia”: blanco o gris muy claro.
- “Construimos el sistema”: blanco.
- “Continuidad”: azul `#0D93F2`, cian o un gradiente azul-celeste muy controlado.
- La bajada: color secundario con contraste suficiente.
- El cierre: blanco, con una línea o marca de color que funcione como firma.

No uses más de un gradiente protagonista.

## Animación

Si agregás movimiento, debe reforzar la idea de continuidad.

Opciones permitidas:

- Una línea que se dibuje una sola vez al entrar en viewport.
- Nodos que aparezcan progresivamente y permanezcan estáticos.
- Reveal corto de las dos partes del título.
- Un desplazamiento lumínico único sobre la línea de trayectoria.

No uses:

- Loops infinitos.
- Pulsos permanentes.
- Partículas continuas.
- Elementos orbitando indefinidamente.
- Animaciones que impidan leer el contenido.

Con `prefers-reduced-motion`, la composición debe mostrarse completa inmediatamente o con una transición mínima.
